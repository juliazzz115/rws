# 📋 Учет клиентов

Веб-приложение для учета клиентов и отслеживания их статусов.

## 🚀 Как использовать

### Локальный запуск

**Вариант 1: Открыть HTML напрямую**
1. Откройте файл `index.html` в браузере
2. Введите NIP и название фирмы
3. Нажмите кнопку "Добавить"
4. Управляйте статусами в таблице

**Вариант 2: Запуск через Node.js сервер**
1. Установите зависимости: `npm install`
2. Запустите сервер: `npm start`
3. Откройте браузер по адресу: `http://localhost:3000`

### Деплой на Railway

1. Создайте аккаунт на [Railway.app](https://railway.app)
2. Подключите ваш GitHub репозиторий
3. Railway автоматически обнаружит проект и настроит деплой
4. После успешного деплоя получите публичный URL вашего приложения

**Альтернативный способ:**
```bash
# Установите Railway CLI
npm install -g @railway/cli

# Войдите в аккаунт
railway login

# Инициализируйте проект
railway init

# Задеплойте приложение
railway up
```

Railway автоматически:
- Установит зависимости (`npm install`)
- Запустит приложение (`npm start`)
- Назначит переменную окружения `PORT`
- Выдаст публичный URL

## ✨ Функции

### Ввод данных клиентов
- Поле поиска для быстрого нахождения клиента по NIP или названию фирмы
- Выпадающий список с доступными клиентами
- Фильтрация списка в реальном времени при вводе текста в поле поиска
- Быстрое добавление выбранного клиента в таблицу

### Отслеживание статусов

**Выбор типа клиента:**
- **Подал сам** - клиент подал документы самостоятельно
- **Оплатил** - клиент оплатил услугу

**Для типа "Подал сам":**
- ✅ Проставлено в CRM - данные внесены в систему
- ✅ Проверено - информация проверена

**Для типа "Оплатил":**
- ✅ Подали - документы поданы
- ✅ Проставлено в CRM - данные внесены в систему
- ✅ Проверено - информация проверена

### Работа с CSV файлами

**Загрузка клиентов из CSV**
- Нажмите кнопку "Загрузить CSV"
- Выберите CSV файл с базой клиентов
- Клиенты добавятся в выпадающий список для выбора
- Используйте поле поиска для быстрого нахождения нужного клиента
- Выберите клиента из списка и нажмите "Добавить в таблицу"

**Экспорт данных в CSV**
- Нажмите кнопку "💾 Экспортировать в CSV"
- Файл с текущими данными автоматически скачается
- Имя файла будет содержать текущую дату

### Формат CSV файла

CSV файл должен содержать только 2 колонки (разделитель: запятая или точка с запятой):

```csv
NIP,Nazwa firmy
"1234567890","ABC Company Sp. z o.o."
"2345678901","XYZ Trading"
"3456789012","Tech Solutions Ltd"
```

**Описание колонок:**
- **NIP** - налоговый номер компании
- **Nazwa firmy** - название фирмы

**Примечание:**
- Первая строка с заголовками автоматически пропускается при загрузке
- Клиенты из CSV попадают в выпадающий список для выбора
- После выбора клиента из списка его можно добавить в таблицу
- Статусы (тип, CRM, проверено и т.д.) устанавливаются уже после добавления в таблицу

Пример файла доступен в `clients_example.csv`

## 💾 Сохранение данных

Все данные автоматически сохраняются в localStorage браузера. При следующем открытии приложения все клиенты и их статусы будут восстановлены.

### 🔄 Синхронизация между устройствами

**Приложение автоматически синхронизирует данные при работе через сервер!**

#### Два режима работы:

**1. Локальный режим (без сервера):**
- Откройте `index.html` напрямую в браузере
- Данные сохраняются только в localStorage на вашем устройстве
- Для обмена данными используйте "Экспортировать CSV"

**2. Серверный режим (с синхронизацией):**
- Запустите сервер: `npm start` (локально) или задеплойте на Railway
- Синхронизация работает автоматически - **никакой настройки не требуется!**
- Все изменения сохраняются на сервере
- Данные обновляются каждые 5 секунд на всех устройствах

#### Преимущества серверного режима:

- ✅ Изменения отображаются на всех устройствах автоматически
- ✅ Несколько человек могут работать одновременно
- ✅ Данные доступны с любого компьютера/телефона
- ✅ Автоматическое резервное копирование на сервере
- ✅ Нулевая настройка - всё работает из коробки!

#### Как это работает:

1. При запуске сервера создается файл `data.json` для хранения данных
2. Приложение автоматически определяет, запущен ли сервер
3. Если сервер доступен - включается синхронизация
4. Если нет - работает локально с localStorage

**Для синхронизации между устройствами просто задеплойте на Railway - всё будет работать автоматически!**
