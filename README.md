# 📋 Учет клиентов

Веб-приложение для учета клиентов и отслеживания их статусов.

## 🚀 Как использовать

1. Откройте файл `index.html` в браузере
2. Выберите клиента из выпадающего списка
3. Нажмите кнопку "Добавить клиента"
4. Управляйте статусами в таблице

## ✨ Функции

### Выбор клиентов
- Выпадающий список с предустановленными именами клиентов
- Добавление выбранного клиента в таблицу одним кликом

### Отслеживание статусов

**Подал / Сам**
- Радио-кнопки для выбора: клиент подал сам или через кого-то

**Пометить / Проверить**
- Чекбоксы для отметки необходимости пометки и проверки

**Статус оплаты**
- Не оплачено
- Подано
- Помечено
- Проверено
- ✅ Оплачено

### Работа с CSV файлами

**Загрузка клиентов из CSV**
- Нажмите кнопку "📂 Загрузить CSV"
- Выберите CSV файл с базой клиентов
- Клиенты автоматически добавятся в таблицу и выпадающий список

**Экспорт данных в CSV**
- Нажмите кнопку "💾 Экспортировать в CSV"
- Файл с текущими данными автоматически скачается
- Имя файла будет содержать текущую дату

### Формат CSV файла

CSV файл должен содержать следующие колонки (разделитель: запятая или точка с запятой):

```csv
Имя клиента,Подал,Сам,Пометить,Проверить,Статус оплаты
"Иванов Иван",1,0,1,0,"Подано"
"Петрова Мария",0,1,0,1,"Оплачено"
```

- **Имя клиента** - текст в кавычках
- **Подал/Сам/Пометить/Проверить** - 1 (да) или 0 (нет)
- **Статус оплаты** - один из: "Не оплачено", "Подано", "Помечено", "Проверено", "Оплачено"

**Примечание:** Первая строка с заголовками автоматически пропускается при загрузке.

Пример файла доступен в `clients_example.csv`

- ✅ Статистика: всего клиентов, оплатили, проверено
- ✅ Автосохранение данных в localStorage браузера
- ✅ Современный адаптивный дизайн
- ✅ Градиентный фон и анимации
- ✅ Поддержка CSV файлов (импорт/экспорт)

## 🎨 Особенности интерфейса

- Красивый градиентный дизайн
- Адаптивная верстка для всех устройств
- Плавные анимации и переходы
- Удобные чекбоксы и выпадающие списки

## 💾 Сохранение данных

Все данные автоматически сохраняются в localStorage браузера. При следующем открытии приложения все клиенты и их статусы будут восстановлены.
