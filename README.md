# 📋 Учет клиентов

Веб-приложение для учета клиентов и отслеживания их статусов.

## 🚀 Как использовать

### Локальный запуск

**Вариант 1: Открыть HTML напрямую**
1. Откройте файл `index.html` в браузере
2. Введите NIP и название фирмы
3. Нажмите кнопку "Добавить"
4. Управляйте статусами в таблице

**Вариант 2: Запуск через Node.js сервер**
1. Установите зависимости: `npm install`
2. Запустите сервер: `npm start`
3. Откройте браузер по адресу: `http://localhost:3000`

### Деплой на Railway

1. Создайте аккаунт на [Railway.app](https://railway.app)
2. Подключите ваш GitHub репозиторий
3. Railway автоматически обнаружит проект и настроит деплой
4. После успешного деплоя получите публичный URL вашего приложения

**Альтернативный способ:**
```bash
# Установите Railway CLI
npm install -g @railway/cli

# Войдите в аккаунт
railway login

# Инициализируйте проект
railway init

# Задеплойте приложение
railway up
```

Railway автоматически:
- Установит зависимости (`npm install`)
- Запустит приложение (`npm start`)
- Назначит переменную окружения `PORT`
- Выдаст публичный URL

## ✨ Функции

### Ввод данных клиентов
- Поле для ввода NIP (налоговый номер)
- Поле для ввода названия фирмы (Nazwa firmy)
- Быстрое добавление клиента в таблицу

### Отслеживание статусов

**Выбор типа клиента:**
- **Подал сам** - клиент подал документы самостоятельно
- **Оплатил** - клиент оплатил услугу

**Для типа "Подал сам":**
- ✅ Проставлено в CRM - данные внесены в систему
- ✅ Проверено - информация проверена

**Для типа "Оплатил":**
- ✅ Подали - документы поданы
- ✅ Проставлено в CRM - данные внесены в систему
- ✅ Помечено - заявка помечена для обработки

### Работа с CSV файлами

**Загрузка клиентов из CSV**
- Нажмите кнопку "Загрузить CSV"
- Выберите CSV файл с базой клиентов
- Клиенты добавятся в выпадающий список для выбора
- Выберите клиента из списка и нажмите "Добавить в таблицу"

**Экспорт данных в CSV**
- Нажмите кнопку "💾 Экспортировать в CSV"
- Файл с текущими данными автоматически скачается
- Имя файла будет содержать текущую дату

### Формат CSV файла

CSV файл должен содержать только 2 колонки (разделитель: запятая или точка с запятой):

```csv
NIP,Nazwa firmy
"1234567890","ABC Company Sp. z o.o."
"2345678901","XYZ Trading"
"3456789012","Tech Solutions Ltd"
```

**Описание колонок:**
- **NIP** - налоговый номер компании
- **Nazwa firmy** - название фирмы

**Примечание:**
- Первая строка с заголовками автоматически пропускается при загрузке
- Клиенты из CSV попадают в выпадающий список для выбора
- После выбора клиента из списка его можно добавить в таблицу
- Статусы (тип, CRM, проверено и т.д.) устанавливаются уже после добавления в таблицу

Пример файла доступен в `clients_example.csv`

## 💾 Сохранение данных

Все данные автоматически сохраняются в localStorage браузера. При следующем открытии приложения все клиенты и их статусы будут восстановлены.

### 🔄 Синхронизация между устройствами

**Приложение использует Firebase Realtime Database для автоматической синхронизации данных!**

Это означает:
- ✅ Изменения отображаются на всех устройствах в реальном времени
- ✅ Несколько человек могут работать одновременно
- ✅ Данные доступны с любого компьютера/телефона
- ✅ Автоматическое резервное копирование в облаке

## 🔧 Настройка Firebase для синхронизации

### Шаг 1: Создание проекта Firebase

1. Перейдите на [Firebase Console](https://console.firebase.google.com/)
2. Нажмите "Добавить проект" (Add project)
3. Введите название проекта (например, "client-tracker")
4. Отключите Google Analytics (не обязательно для этого проекта)
5. Нажмите "Создать проект"

### Шаг 2: Настройка Realtime Database

1. В меню слева выберите **Build → Realtime Database**
2. Нажмите "Создать базу данных" (Create Database)
3. Выберите регион (например, europe-west1)
4. Выберите режим "Начать в **тестовом режиме**" (Start in **test mode**)
5. Нажмите "Включить" (Enable)

### Шаг 3: Получение конфигурации

1. Перейдите в **Настройки проекта** (иконка шестеренки → Project settings)
2. Прокрутите вниз до раздела "Ваши приложения" (Your apps)
3. Нажмите на иконку **</>** (Web)
4. Введите название приложения (например, "client-tracker-web")
5. Нажмите "Зарегистрировать приложение"
6. Скопируйте объект `firebaseConfig`

### Шаг 4: Обновление кода

Откройте файл `index.html` и замените конфигурацию Firebase (строки 294-302):

```javascript
const firebaseConfig = {
    apiKey: "ВАШ_API_KEY",
    authDomain: "ВАШ_PROJECT_ID.firebaseapp.com",
    databaseURL: "https://ВАШ_PROJECT_ID-default-rtdb.europe-west1.firebasedatabase.app",
    projectId: "ВАШ_PROJECT_ID",
    storageBucket: "ВАШ_PROJECT_ID.appspot.com",
    messagingSenderId: "ВАШ_SENDER_ID",
    appId: "ВАШ_APP_ID"
};
```

### Шаг 5: Настройка правил безопасности (опционально)

Для продакшена рекомендуется настроить правила безопасности:

1. В Realtime Database перейдите на вкладку "Правила" (Rules)
2. Замените правила на:

```json
{
  "rules": {
    "clients": {
      ".read": true,
      ".write": true
    },
    "availableClients": {
      ".read": true,
      ".write": true
    }
  }
}
```

**Готово!** Теперь ваши данные синхронизируются между всеми устройствами в реальном времени.

### Альтернатива без Firebase

Если вы не хотите настраивать Firebase:
- Приложение будет работать с localStorage (данные только на одном устройстве)
- Используйте "Экспортировать CSV" для обмена данными между устройствами
- Данные сохраняются локально в браузере
