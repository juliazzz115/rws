# Скрипт перевірки NIP через CEIDG API

Автоматична перевірка польських NIP (номерів платників податків) через публічний API CEIDG (Centralna Ewidencja i Informacja o Działalności Gospodarczej).

## Опис

Скрипт дозволяє:
- ✅ Перевіряти валідність NIP
- ✅ Отримувати дату початку діяльності компанії
- ✅ Перевіряти назву фірми
- ✅ Дізнаватися статус діяльності (активна, призупинена, тощо)
- ✅ Обробляти масово список NIP з CSV файлу

## Встановлення

### 1. Встановіть Python 3.7+

Переконайтесь, що у вас встановлений Python версії 3.7 або новіше:

```bash
python --version
```

### 2. Встановіть залежності

```bash
pip install -r requirements.txt
```

або

```bash
pip install requests
```

## Використання

### Формат вхідного CSV файлу

Створіть файл `clients_individual.csv` з наступними колонками:

```csv
NIP,Nazwa firmy
1234567890,Nazwa firmy 1
9876543210,Nazwa firmy 2
```

**Обов'язкові колонки:**
- `NIP` - польський номер платника податків (10 цифр)
- `Nazwa firmy` - назва фірми

### Запуск скрипту

```bash
cd scripts
python check_nip_ceidg.py
```

### Зміна шляху до вхідного файлу

Відредагуйте рядок 136 у файлі `check_nip_ceidg.py`:

```python
input_file = "ваш_файл.csv"  # Змініть на своє ім'я файлу
```

### Вихідний файл

Скрипт створить файл з результатами у форматі:
```
nip_dates_result_YYYYMMDD_HHMMSS.csv
```

**Колонки у вихідному файлі:**
- `nip` - перевірений NIP
- `nazwa_z_pliku` - назва з вхідного файлу
- `nazwa_z_ceidg` - назва з бази CEIDG
- `data_rozpoczecia` - дата початку діяльності
- `status` - статус діяльності
- `found` - чи знайдено в CEIDG (True/False)
- `error` - опис помилки (якщо є)

## Особливості

### Обмеження швидкості
Скрипт має затримку 2 секунди між запитами, щоб не перевантажувати API CEIDG.

### Автоматичне збереження
Результати зберігаються кожні 50 оброблених записів, щоб не втратити прогрес у випадку помилки.

### Фільтрація тестових NIP
Скрипт автоматично пропускає тестові NIP:
- 1111111111
- 0000000009
- 0000090099
- 0000000333
- 0000000000

### Валідація NIP
Перевіряється, що NIP:
- Складається рівно з 10 символів
- Містить тільки цифри

## API CEIDG

Скрипт використовує публічний API CEIDG v2:
```
https://dane.biznes.gov.pl/api/ceidg/v2/firma/{NIP}
```

Документація API: https://dane.biznes.gov.pl/
